# Jar Classes

### The following files are need:
 
- json-20211205.jar (Closest to assignment example)
- commons-cli-1.9.0.jar
- skyview.jar (Has errors: uses error handling to pass)

### How to run the jar files:

1. Open your terminal and change directories to the week5 folder. 
2. Change directories one more time accesing the src folder path should look like: 
   - /Users/me/pathto/Week5/src 
3. Once you are in the src file, compile the java file:
   - javac JarClasses.java
4. Then run the file you would like to access:
   - For the JSON jar (closest to assignment example)
      - java JarClasses ../json-20211205.jar
   - For Commons-cli jar
      - java JarClasses ../commons-cli-1.9.0.jar
   - For NASA skyview jar
      - java JarClasses ../skyview.jar
